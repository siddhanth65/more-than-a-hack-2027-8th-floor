These logs are the look budget. `sealed.jsonl` records every read of the sealed simulated match and `public.jsonl` every read of the public 5-minute window, one JSON object per line, aggregates only (never labels or per-frame data). The scripts consult them to refuse repeat or over-budget reads, and they are tracked by git so the budget survives clones and branch switches. Never delete or rewrite entries; the public window had one read done by hand before logging began, so the guard counts that as one extra.
